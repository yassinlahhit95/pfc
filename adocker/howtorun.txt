REQUISITOS
----------
- Docker Desktop instalado y en ejecucion


CONTENIDO DE LA CARPETA DOCKER
-------------------------------
  Dockerfile             -> imagen PHP + Apache
  docker-compose.yml     -> orquesta la app y la base de datos
  database.sql           -> base de datos completa con estructura y datos
  secrets.php            -> clave API de correos (Brevo)
  service-account.json   -> credenciales Firebase para notificaciones push
  howtorun.txt           -> este archivo


PASOS PARA EJECUTAR
-------------------
1. Abre una terminal en esta carpeta (docker/)

2. Ejecuta:
   docker compose up --build

3. Espera a que termine (la primera vez tarda unos minutos)

4. Abre el navegador en:
   http://localhost:8080


PARAR LA APLICACION
-------------------
  docker compose down

Para parar y borrar tambien la base de datos y los archivos subidos:
  docker compose down -v


NOTAS
-----
- El puerto 8080 debe estar libre en tu maquina
- La base de datos y los archivos subidos persisten entre reinicios
- Solo usar "down -v" si quieres un reinicio completo desde cero
